# 网页地图使用说明

使用 `tracktool-map` 启动网页地图。源码运行时可用以下命令指定归档、服务端文件目录和任务状态目录：

```sh
pnpm start --archive /数据/归档 --files-root /数据 --state-dir /数据/网页状态 --no-browser
```

需要在手机或其他电脑上访问时，将服务绑定到可信局域网，并使用运行服务电脑的 IPv4 地址：

```sh
pnpm start --host 0.0.0.0 --archive /数据/归档 --files-root /数据 --state-dir /数据/网页状态
```

网页始终使用后台配置的单一轨迹库。KML 导入会写入当前库；图片项目 JSON 中的轨迹引用也绑定当前库。网页不提供数据库上传、库路径选择或建库功能。

在“轨迹处理”中选择库内行程，可在同一 KML 中断开、删点、补绘或调整片段连接。先预览，再应用为新版本；历史版本可以下载或恢复。独立文件工具可以使用地图上已选轨迹的副本，也可以上传文件或选择服务端 KML。独立文件工具的结果不会自动写入轨迹库。

服务端文件浏览只访问运行 Node 的电脑。`--files-root` 可重复指定；指定后会替代默认目录范围。浏览器上传的文件会写入任务状态目录，不会修改客户端原件；单个文件最大 8 GiB。处理记录面板可查看结果并清理上传批次。被排队或运行任务使用的批次不能清理，超过 7 天且未被活动任务引用的批次会在服务启动时清理。

网页设置用于调整底图、标注、地图要素和叠加层。标题、轨迹样式、画框和 PNG 输出位于“轨迹 → 轨迹导出”。日志、备份目录、API 密钥和分类等服务配置通过 CLI 或后台管理。

普通文件操作的预览 15 分钟有效，库内版本编辑预览 24 小时有效。刷新浏览器或断开连接不会停止后台任务。取消只会阻止尚未完成的工作，已经完成的文件修改不会回滚。处理记录可在服务重启后查看；已中断任务不会自动重放。

结果下载读取任务登记的服务端文件；之后修改、移动或清理该文件会影响下载。局域网访问适用于可信网络和单用户场景，不提供多用户账户隔离。
