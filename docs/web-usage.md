# 网页地图使用说明

启动固定轨迹库的本地服务：

```sh
pnpm start --archive /数据/归档 --files-root /数据 --state-dir /数据/网页状态 --no-browser
```

可信局域网可加 `--host 0.0.0.0`，从手机访问服务电脑的 IPv4 地址和端口。网页始终使用后台配置的一个轨迹库，不上传、选择或建立 SQLite 库；初次建库、旧 ZIP 导入和服务配置通过 CLI 完成。没有云同步或多用户账户隔离。

## 浏览地图

左上角保留“轨迹／设置”。轨迹入口页仅提供“轨迹列表、上传轨迹、导出轨迹”；导出面板通过下拉框选择 ZIP、聚合 KML 或 PNG 图像，选定后显示对应选项；点击“轨迹列表”进入独立列表面板，左上角返回箭头回到入口页。归档状态检查和数据库升级通过 CLI 使用，网页不再提供入口。刷新不会停止后台工作。

轨迹列表以行程名称为主，详情显示完整归档路径。日期优先取 KML 起始点时间对应的东八区（UTC+8）日期，其次取文件名日期；都不存在时显示“行程日期未知”，不使用导入时间。活动标签来自 KML，距离为后台按原始分段计算的 WGS84 测地距离，不含额外连接线。元数据随可重建的概览缓存更新，不修改归档结构。列表标题栏依次为可见性眼睛按钮、筛选漏斗按钮、搜索框、排序箭头按钮。搜索框直接筛选名称；漏斗打开分类和日期弹窗，按“应用”生效，“取消”放弃更改，“重置”恢复默认筛选后仍需应用。排序箭头打开排序选项，选择后立即生效。日期范围会排除日期未知的轨迹，支持按完整起始点时间升降序（保留微秒精度）、名称排序和按东八区月份分组。日期筛选包含起止两天，跨天行程按起始点日期匹配；只有文件名日期时按该日东八区零点参与排序，日期未知的轨迹排在末尾。

- 每条轨迹的眼睛按钮只控制该轨迹的地图显示。列表上方的可见性按钮切换当前列表所有轨迹（包含所有分页）：全部可见时全部隐藏，否则全部显示。
- 搜索、分类和日期范围只筛选列表；可见性按钮只修改当前筛选结果，不影响范围之外的轨迹。无筛选时控制全库；若只想显示某个筛选结果，可先在无筛选时清空显示，再筛选并全部显示。改变筛选不会自动改变地图显示。
- “批量操作”才出现复选框。跨页选择保留，操作栏显示数量；“选择当前页”和“选择全部筛选结果（数量）”范围明确。可加入新建／当前工程、将所选原始 KML 打包为一个 ZIP 下载（每批最多 200 条、原始内容合计 128 MiB，超出需分批，不截断）。取消选择不改变地图显示。
- 出图工程最多 200 条，超过时明确报错，不截断选择。工程内容与地图显示、列表筛选、批量选择分别保存。

悬停或键盘聚焦列表项只高亮，不移动地图；点击列表项或地图轨迹打开同一侧栏内的详情。重叠轨迹在侧栏列出候选，触屏可直接点选。详情和候选不遮挡地图操作，“定位此轨迹”按整个地图视口定位，不扣除侧栏或底部面板遮挡。各面板的返回导航统一为标题栏左上角的箭头；编辑页返回详情，详情返回列表，返回列表恢复搜索、分页和滚动位置。浏览视角、搜索、分类、日期、地图显示与批量选择在当前浏览器标签页内保留。

手机上所有普通工具使用同一个底部面板，可拖动顶部横条，在收起、半屏和展开三个高度吸附，也可轻点横条切换；点击左上或右上对应的工具图标关闭；定位保持面板当前高度，可自行拖动收起；拖动地图和滚动面板分别处理。桌面使用同侧列表／详情切换。

速度图按附近数据的相对异常程度缩放纵轴，不依赖车型、已知最高速度或固定加速度阈值。检测在原始点抽样前进行，分别对速度及其变化率使用局部 Hampel 检测：前后各 60 秒、至少 7 个参考值、3 倍稳健标准差；平稳区间使用相对噪声下限，避免极小波动被放大。缺失或非递增时间、超过 60 秒的记录缺口会分开处理，边界允许使用单侧参考；一分钟窗口内参考不足时，在同一连续记录段内补取最近的有效邻点，仍不跨长缺口；首轮异常不再参与第二轮的参考统计。突发的真实加减速也可能被标记，持续平稳的高速则不会仅因绝对速度高而被标记。异常标记只影响速度图纵轴上限，原始速度、统计值和轨迹数据保留；超出图表范围的点仍可悬停查看原值。方法参考 [Hampel 检测说明](https://www.mathworks.com/help/signal/ref/hampel.html)。

## KML 入库

“轨迹 → 上传轨迹”打开专用入库面板：

1. 选择或拖入一个或多个 KML。上传、校验、导入结果都在同一份文件列表中显示，默认按文件内容识别分类。
2. 重复轨迹标为“将跳过”；同名但内容不同、无法识别分类或无效 KML 会明确提示。展开对应文件的“修改名称或分类”可逐个修正，也可移除异常文件。名称须包含 `YYYY-MM-DD` 日期。修改后点击“重新校验”；页面使用仍在浏览器中的文件重新上传，无需再次选取。
3. 全部文件可处理后，点击“导入 N 条轨迹”。任何上传失败、校验异常或名称冲突都会阻止整批导入，不会静默只导入成功的部分。上传和校验时可取消。
4. 成功后显示新增及跳过数量，可逐条“查看轨迹”或“继续上传”。全部为重复文件时直接显示跳过结果。页面不展示内部任务、日志、文件路径等信息。
5. 校验不修改归档；提交前再次检查文件和归档指纹，同一次确认的文件整体入库。若提交后网络中断，可“查询导入结果”；同一次提交只执行一次。

当前设备和服务端的源文件均保留，不创建或依赖 Backup 目录。上传副本只用于预览和确认入库；入库成功、失败、取消或中断后均自动清理，失败或过期的预览也会清理。预览通过后暂时保留到确认或过期。页面仍保留已选择的设备文件时，可直接重新校验；离开或刷新页面后需重新选择文件。清理只针对上传副本，不删除服务端或 CLI 原文件，也不清理仍被排队、运行任务使用的文件。重复内容不新增轨迹版本；同名内容不同的冲突不会覆盖原轨迹，也不会写入本批其他文件。数据库提交成功后，即使连接断开导致网页未收到成功响应，已经完整提交的数据仍会保留；重新上传会识别为重复。网页不再提供“恢复中断操作”。CLI 默认同样不搬移源文件；只有显式使用 `--move` 才启用旧的 Backup 搬移及恢复流程。

KML 入库页面仅显示上传文件名，不提供完整路径输入或上传目录选择。单文件上传上限 8 GiB。任务使用中的副本延后清理；服务重启后会补做已结束任务的清理。尚未提交预览的遗留批次仍由超过 7 天的启动清理兜底。

## 编辑轨迹与版本

“编辑轨迹”中的“断开轨迹／删除一段”分别用于同一行程内断开和删除点范围。直接在主地图选择断开位置，或先后选择要删除范围的两个端点（包含两端）；红色标记删除范围，橙色标记断开位置，绿色标记预览中的新增片段。自动检测先显示候选，可以排除后保存。精确点序号放在“高级”；删除范围输入包含起点、不包含终点，索引从 0 开始。地图点击经过底图坐标系转换，使用完整原始分段的真实点索引，不使用概览简化线。编辑几何和目标固定到同一历史快照；其他面板或外部修改不会把旧点索引自动套到新版本。来源过期时可明确读取最新版本，放弃旧草稿后重新选择。

轨迹详情提供三个入口：“编辑轨迹”先选择断开、删除轨迹点、补绘、补高程、修改标签或拆分行程，再进入专用界面。断开和删除通过地图选点，片段可点击高亮定位；补绘可吸附已有端点。拆分以行程名称和活动标签分组，文件路径自动生成，地图用颜色区分各组；“调整显示”通过片段列表拖动排序、眼睛按钮显隐以及片段之间的连接按钮调整展示，支持全部连接／断开。点击片段可高亮定位，地图即时反馈，底部统一保存或放弃修改；“查看历史操作”按时间倒序列出轨迹编辑和显示调整，并标记当前状态。点击记录在地图查看当时的轨迹，可回到当前、下载当时的 KML，或通过确认弹窗恢复轨迹及显示设置。拆分记录提供“撤销拆分”，确认前列出恢复和移出列表的行程；存在后续修改时阻止撤销。历史页不再显示版本配对、来源明细或任务日志。网页不再提供组合库内片段功能，也不再显示重复的处理记录列表。连接／忽略是轨迹库默认展示设置；工程自己的覆盖在工程“内容”中设置，作用范围不同。

断开、删除片段、手绘和标签修改点击保存即可完成；显示设置在地图即时预览后保存。补高程、拆成多行程、恢复版本和撤销操作先显示结果或影响范围，再确认保存。后端仍会自动完成预览校验，再提交新版本；不会跳过来源版本检查。原件和旧版本保留，库内更新不会改变工程固定的历史版本。普通面板切换保留编辑草稿；尚未生成预览的草稿只保留在当前页面，刷新或关闭时会提示未保存修改；页面不显示任务日志和预览有效期。补高程显示补齐与未补齐的点数，拆分通过简洁弹窗确认；来源变化时可重新载入轨迹，后端保留幂等与并发校验。

库内行程编辑统一从具体行程详情的三个入口进入，不再提供独立入口。网页不再提供独立文件处理工具；独立 KML 文件处理可使用命令行。已有任务记录和结果保留，但不能从网页重新执行独立文件处理任务。

取消任务只阻止尚未完成的工作，不是回滚。删除整条轨迹及其历史是不可从版本历史撤销的操作，预览会显示影响和阻塞依赖；不能把它当作普通编辑撤销。

## 制作地图与工程管理

在“导出轨迹”中选择“PNG图像”，即可新建或打开独立出图工程。新建可以为空，也可从批量所选轨迹建立；不把地图眼睛开关自动当作工程内容。顶部始终显示当前工程名称和保存状态，提供“保存／另存为／退出工程”。普通保存更新当前目标；只有另存遇到重名才确认。选择待打开工程不会改变当前保存目标，按“载入项目”才加载。

工程内的“从轨迹库添加／添加轨迹”用于临时查找，定位和拖动不改变原构图。“回到工程”恢复工程视角。退出有未保存修改的工程时提供保存、放弃和取消，退出后恢复进入前的浏览视角、筛选与显示。

设置分为“内容／样式／画框与输出／更多”：

- 内容支持搜索工程轨迹、移除单条／搜索结果／全部，以及从轨迹库批量添加，显示数量／200 上限。项目段设置可覆盖连接、忽略和顺序；“采用库中当前版本并重置项目覆盖”是显式更新，原有固定历史不会自动跟随库修改。
- 样式设置标题、轨迹颜色和线宽；底图在设置面板调整。
- 画框与输出设置比例、像素尺寸和构图预览。保存常驻顶部，导出按钮固定在面板底部，不被长轨迹设置列表挤走。
- 更多包含待打开工程、JSON 导入导出等低频功能。资源版本变化会提示确认；缺失轨迹或资源未确认时不能保存／导出。

导出内容不同：原始 KML 保留原件完整字节，在轨迹详情或批量下载；展示 KML 包含当前工程连接／忽略等展示语义；PNG 是地图图片。ZIP、聚合 KML 和 PNG 图像统一在“导出轨迹”的类型下拉框中选择。完整历史和工程的备份仍使用 SQLite 完整备份。

## 任务与恢复

任务及事件仍保存在服务端独立 SQLite 中；中断写任务不会自动重放。网页在当前操作页面显示进度与结果，不再提供独立的处理记录面板和暂存文件管理列表。

错误在相关面板或地图错误区持续展示，普通成功消息短暂显示。底图切换失败保留原地图；资源错误可重试，网络恢复会重试失败资源。重新聚焦窗口不重建主地图。结果下载依赖任务登记的服务端文件，移动或清理后可能无法下载。

ZIP 和聚合 KML 导出只需点击“导出”，后台自动完成检查和生成，完成后自动下载，结果中的下载按钮可再次下载。删除轨迹会自动读取影响范围，只需一次“确认删除”。

轨迹详情的“下载轨迹”直接返回当前详情展示版本的原始 KML，内部按内容摘要绑定版本。不会创建处理任务或落盘到 uploads，也不显示版本 ID、结果或日志面板。历史版本下载仅在“查看历史操作”中提供。
