# 网页地图使用说明

启动固定轨迹库的本地服务：

```sh
pnpm start --archive /数据/归档 --files-root /数据 --state-dir /数据/网页状态 --no-browser
```

可信局域网可加 `--host 0.0.0.0`，从手机访问服务电脑的 IPv4 地址和端口。网页始终使用后台配置的一个轨迹库，不上传、选择或建立 SQLite 库；初次建库、旧 ZIP 导入和服务配置通过 CLI 完成。没有云同步或多用户账户隔离。

## 浏览地图

左上角保留“轨迹／设置”。轨迹入口页仅提供“轨迹列表、上传轨迹、导出轨迹”；导出面板通过下拉框选择 ZIP、聚合 KML 或 PNG 图像，选定后显示对应选项；点击“轨迹列表”进入独立列表面板，左上角返回箭头回到入口页。归档状态检查和数据库升级通过 CLI 使用，网页不再提供入口。刷新不会停止后台工作。设置首页提供“配色”和“地图设置”。配色可选浅色、深色或跟随系统（默认），同时控制应用界面与支持切换配色的地图，并在当前浏览器自动保存；跟随系统会实时响应系统主题变化。固定配色的地图和卫星影像保留原貌。点击“地图设置”进入地图选项，左上角返回箭头可回到设置首页。地图设置中的图源、地图要素和叠加层会自动保存到状态目录的 `display.json`（默认 `~/.local/state/tracktool/`），下次打开继续使用；删除该文件可恢复默认。

画布坐标系跟随底图：OpenFreeMap 矢量底图和 WGS84 底图按 WGS84 渲染，高德、腾讯、谷歌、360、必应地形这类国内偏移底图按 GCJ-02 渲染，瓦片直接输出，文字和细线更清晰。WGS84 画布上可以叠加 GCJ-02 注记（会自动重采样），例如 Esri 卫星搭配高德注记；GCJ-02 画布不能叠加 WGS84 图层（铁路、海事、电力、天地图注记），也不加载 OSM 矢量要素（道路、建筑、水系等）。「OpenFreeMap 矢量底图」的瓦片来自 OpenFreeMap（© OpenMapTiles © OpenStreetMap contributors），浅色／深色配色由设置首页的「配色」统一控制，与图源互不影响。首次加载需要纠偏的图片可能稍慢，后续会复用缓存；文字和细线可能因图片重采样略有柔化，国境与港澳台附近仍应核对对齐情况。底图已经提供的内容会显示来源，无法单独关闭；路网注记和铁路主题通过单选切换，选择新来源会替换同类图层。网页浏览与 PNG 导出使用相同的对齐方式。

“地图设置”子面板包含图源选择、路网、常用信息和附加图层。底图使用纵向两栏选择器：左栏选供应商，右栏选该供应商的底图，两栏各自限高、可滚动；OSM、memomaps、OpenTopoMap、OpenFreeMap 等来源统一归入“开放地图”，其余按商业厂商分组。选中矢量底图后会出现“配色”。“路网”下拉框选择道路与地名注记来源，右侧数字框调整其不透明度；“常用信息”下按“边界与轮廓”“名称”“其它”三类缩进分组，每项右侧的胶囊单选按钮切换该要素的显示取值。底图或注记已经提供的内容、以及当前底图无法叠加的图层都不再显示控件，切换回兼容底图后恢复。

“附加图层”固定列出铁路、航标和电力，各自由右端的开关启用或停用，开启后开关左侧出现不透明度数字输入框；图层名右侧显示当前配置摘要。点击图层名（或名称前的箭头）展开设置，铁路可切换显示内容，电力可调整设施与最低电压，航标没有额外设置。关闭开关会保留该图层的参数；电力设施选择“仅线路”时，最低电压仍会筛选线路。当前底图无法叠加的图层直接不显示。切换底图导致图层关闭时不再提示，只保留配置，切回兼容底图后可手动开启；地图要素的原有设置会在兼容底图下恢复。

切换底图时仍显示当前底图，失败可在错误提示中重试。浏览地图自动保存，失败可重试保存；出图工程中的修改仅作用于当前工程，保存工程后保留。

轨迹列表以行程名称为主，详情显示完整归档路径。日期优先取 KML 起始点时间对应的东八区（UTC+8）日期，其次取文件名日期；都不存在时显示“行程日期未知”，不使用导入时间。活动标签来自 KML，距离为后台按原始分段计算的 WGS84 测地距离，不含额外连接线。元数据随可重建的概览缓存更新，不修改归档结构。列表标题栏依次为可见性眼睛按钮、筛选漏斗按钮、搜索框、排序箭头按钮。搜索框直接筛选名称；漏斗打开分类和日期弹窗，按“应用”生效，“取消”放弃更改，“重置”恢复默认筛选后仍需应用。排序箭头打开排序选项，选择后立即生效。日期范围会排除日期未知的轨迹，支持按完整起始点时间升降序（保留微秒精度）、名称排序和按东八区月份分组。日期筛选包含起止两天，跨天行程按起始点日期匹配；只有文件名日期时按该日东八区零点参与排序，日期未知的轨迹排在末尾。

- 每条轨迹的眼睛按钮只控制该轨迹的地图显示。列表上方的可见性按钮切换当前列表所有轨迹（包含所有分页）：全部可见时全部隐藏，否则全部显示。
- 搜索、分类和日期范围只筛选列表；可见性按钮只修改当前筛选结果，不影响范围之外的轨迹。无筛选时控制全库；若只想显示某个筛选结果，可先在无筛选时清空显示，再筛选并全部显示。改变筛选不会自动改变地图显示。
- “批量操作”才出现复选框。跨页选择保留，操作栏显示数量；“选择当前页”和“选择全部筛选结果（数量）”范围明确。可加入新建／当前工程、将所选原始 KML 打包为一个 ZIP 下载（每批最多 200 条、原始内容合计 128 MiB，超出需分批，不截断）。取消选择不改变地图显示。
- 出图工程最多 200 条，超过时明确报错，不截断选择。工程内容与地图显示、列表筛选、批量选择分别保存。

悬停或键盘聚焦列表项只高亮，不移动地图；点击列表项或地图轨迹打开同一侧栏内的详情。重叠轨迹在侧栏列出候选，触屏可直接点选。详情和候选不遮挡地图操作，“定位此轨迹”按整个地图视口定位，不扣除侧栏或底部面板遮挡。各面板的返回导航统一为标题栏左上角的箭头；编辑页返回详情，详情返回列表，返回列表恢复搜索、分页和滚动位置。浏览视角、搜索、分类、日期、地图显示与批量选择在当前浏览器标签页内保留。

手机上所有普通工具使用同一个底部面板，可拖动顶部横条，在收起、半屏和展开三个高度吸附，也可轻点横条切换；点击左上或右上对应的工具图标关闭；定位保持面板当前高度，可自行拖动收起；拖动地图和滚动面板分别处理。桌面使用同侧列表／详情切换。

速度图按附近数据的相对异常程度缩放纵轴，不依赖车型、已知最高速度或固定加速度阈值。检测在原始点抽样前进行，分别对速度及其变化率使用局部 Hampel 检测：前后各 60 秒、至少 7 个参考值、3 倍稳健标准差；平稳区间使用相对噪声下限，避免极小波动被放大。缺失或非递增时间、超过 60 秒的记录缺口会分开处理，边界允许使用单侧参考；一分钟窗口内参考不足时，在同一连续记录段内补取最近的有效邻点，仍不跨长缺口；首轮异常不再参与第二轮的参考统计。突发的真实加减速也可能被标记，持续平稳的高速则不会仅因绝对速度高而被标记。异常标记只影响速度图纵轴上限，原始速度、统计值和轨迹数据保留；超出图表范围的点仍可悬停查看原值。方法参考 [Hampel 检测说明](https://www.mathworks.com/help/signal/ref/hampel.html)。

## KML 入库

“轨迹 → 上传轨迹”打开专用入库面板：

1. 选择或拖入一个或多个 KML。上传、校验、导入结果都在同一份文件列表中显示，默认按文件内的 TrackTags 识别活动标签与分类。
2. 重复轨迹标为“重复轨迹”；同名但内容不同、无法识别活动标签或无效 KML 会明确提示。点击对应文件的三点按钮可逐个修正，也可移除异常文件。名称须包含 `YYYY-MM-DD` 日期。保存修改、添加或移除文件后，自动重新核对整批文件。修改名称或标签时复用已上传的副本和解析结果，添加文件时只上传、解析新增文件；新增或修改的行显示检查中，其他行保留结果，核对完成后更新冲突和重复状态。检查失败可点击文件旁的重试图标，无需再次选取。
3. 全部文件可处理后，点击“导入”。任何上传失败、校验异常或名称冲突都会阻止整批导入，不会静默只导入成功的部分。上传和校验时可取消。
4. 成功后显示新增及跳过数量，可逐条“查看轨迹”或“添加文件”。全部为重复文件时直接显示跳过结果。页面不展示内部任务、日志、文件路径等信息。
5. 改名称只重新计算导入位置，改标签只重新计算该文件修改后的内容指纹；每次仍统一核对本批文件和当前轨迹库的重复、冲突关系。文件内容改变或解析缓存过期后会重新解析，分类配置变化也会立即参与检查。校验不修改归档；提交前再次检查文件和归档指纹，同一次确认的文件整体入库。入库成功后默认自动补全新轨迹的起终点行政区（需要已配置 Google API key；可用 `auto_fill_locations=false` 关闭），补全失败不影响已入库轨迹。若提交后网络中断，可“查询导入结果”；同一次提交只执行一次。

当前设备和服务端的源文件均保留，不创建或依赖 Backup 目录。上传副本只用于预览和确认入库；入库成功、失败、取消或中断后均自动清理。网页预检查的副本（包括检查未通过的文件）会暂时保留供修正后复用，移除文件、离开面板或预检查超过 15 分钟后清理；副本已过期时，再次检查会自动重新上传。页面仍保留已选择的设备文件时，可直接重新校验；离开或刷新页面后需重新选择文件。清理只针对上传副本，不删除服务端或 CLI 原文件，也不清理仍被排队、运行任务使用的文件。重复内容不新增轨迹版本；同名内容不同的冲突不会覆盖原轨迹，也不会写入本批其他文件。数据库提交成功后，即使连接断开导致网页未收到成功响应，已经完整提交的数据仍会保留；重新上传会识别为重复。网页不再提供“恢复中断操作”。CLI 默认同样不搬移源文件；只有显式使用 `--move` 才启用旧的 Backup 搬移及恢复流程。

KML 入库页面仅显示上传文件名，不提供完整路径输入或上传目录选择。单文件上传上限 8 GiB。任务使用中的副本延后清理；服务重启后会补做已结束任务的清理。尚未提交预览的遗留批次仍由超过 7 天的启动清理兜底。

## 编辑轨迹与版本

“编辑轨迹”中的“断开轨迹／删除一段”分别用于同一行程内断开和删除点范围。直接在主地图选择断开位置，或先后选择要删除范围的两个端点（包含两端）；红色标记删除范围，橙色标记断开位置，绿色标记预览中的新增片段。自动检测先显示候选，可以排除后保存。精确点序号放在“高级”；删除范围输入包含起点、不包含终点，索引从 0 开始。地图点击与轨迹统一使用 WGS84 坐标，并使用完整原始分段的真实点索引，不使用概览简化线。编辑几何和目标固定到同一历史快照；其他面板或外部修改不会把旧点索引自动套到新版本。来源过期时可明确读取最新版本，放弃旧草稿后重新选择。

轨迹详情提供三个入口：“编辑轨迹”先选择断开、删除轨迹点、补绘、填充高程、修改标签或拆分行程，再进入专用界面。断开和删除通过地图选点，片段可点击高亮定位；补绘支持“地图绘制”和“上传轨迹”：地图绘制可吸附已有端点；导入上传本地 KML 文件（最大 8 MiB），只接受恰好一条、不带时间的 LineString，至少两个点，不接受多条线、gx:Track 或带 TimeStamp／TimeSpan 的文件。导入后先在地图检查，点击“保存”插入；保留原始坐标与高程，不吸附端点。在“分段管理”的片段间点击“插入补绘轨迹”也可使用这两种方式。拆分行程按片段顺序设置分界：在相邻片段之间点击“在此拆分”，后面的连续片段会成为新行程；点击“并入上一行程”可取消分界，保留上一行程的名称和标签。各行程可分别填写名称、选择活动标签，文件路径自动生成，地图用颜色区分各组；“调整显示”通过片段列表拖动排序、眼睛按钮显隐以及片段之间的连接按钮调整展示，支持全部连接／断开。点击片段可高亮定位，地图即时反馈，底部统一保存或放弃修改；“查看历史操作”按时间倒序列出轨迹编辑和显示调整，并标记当前状态。点击记录在地图查看当时的轨迹，可回到当前、下载当时的 KML，或通过确认弹窗恢复轨迹及显示设置。拆分记录提供“撤销拆分”，确认前列出恢复和移出列表的行程；存在后续修改时阻止撤销。历史页不再显示版本配对、来源明细或任务日志。网页不再提供组合库内片段功能，也不再显示重复的处理记录列表。连接／忽略是轨迹库默认展示设置；工程自己的覆盖在工程“内容”中设置，作用范围不同。

断开、删除片段、手绘和标签修改点击保存即可完成；显示设置在地图即时预览后保存。填充高程、拆成多行程、恢复版本和撤销操作先显示结果或影响范围，再确认保存。后端仍会自动完成预览校验，再提交新版本；不会跳过来源版本检查。原件和旧版本保留，库内更新不会改变工程固定的历史版本。普通面板切换保留编辑草稿；尚未生成预览的草稿只保留在当前页面，刷新或关闭时会提示未保存修改；页面不显示任务日志和预览有效期。填充高程逐点查询缺失高程，查询前显示缺失点数并区分整段缺失和部分缺失的片段，查询完成后显示查询成功与失败的点数，并按片段分组逐点列出经纬度和新高程，可点击定位；高程数据完整的轨迹无需填充高程，面板会提示并禁用查询按钮。拆分通过简洁弹窗确认；来源变化时可重新载入轨迹，后端保留幂等与并发校验。

库内行程编辑统一从具体行程详情的三个入口进入，不再提供独立入口。网页不再提供独立文件处理工具；独立 KML 文件处理可使用命令行。已有任务记录和结果保留，但不能从网页重新执行独立文件处理任务。

取消任务只阻止尚未完成的工作，不是回滚。删除整条轨迹及其历史是不可从版本历史撤销的操作，预览会显示影响和阻塞依赖；不能把它当作普通编辑撤销。

## 制作地图与工程管理

在“导出轨迹”中选择“PNG图像”，即可新建或打开独立出图工程。新建可以为空，也可从批量所选轨迹建立；不把地图眼睛开关自动当作工程内容。顶部始终显示当前工程名称和保存状态，提供“保存／另存为／退出工程”。普通保存更新当前目标；只有另存遇到重名才确认。选择待打开工程不会改变当前保存目标，按“载入项目”才加载。

工程内的“从轨迹库添加／添加轨迹”用于临时查找，定位和拖动不改变原构图。“回到工程”恢复工程视角。退出有未保存修改的工程时提供保存、放弃和取消，退出后恢复进入前的浏览视角、筛选与显示。

设置分为“内容／样式／画框与输出／更多”：

- 内容支持搜索工程轨迹、移除单条／搜索结果／全部，以及从轨迹库批量添加，显示数量／200 上限。项目段设置可覆盖连接、忽略和顺序；“采用库中当前版本并重置项目覆盖”是显式更新，原有固定历史不会自动跟随库修改。
- 样式设置标题、轨迹颜色和线宽；底图在“地图设置”中调整。工程地图同样跟随全局配色，保存工程与导出 PNG 时使用当时的地图配色。
- 画框与输出设置比例、像素尺寸和构图预览。保存常驻顶部，导出按钮固定在面板底部，不被长轨迹设置列表挤走。
- 更多包含待打开工程、JSON 导入导出等低频功能。资源版本变化会提示确认；缺失轨迹或资源未确认时不能保存／导出。

导出内容不同：原始 KML 保留原件完整字节，在轨迹详情或批量下载；展示 KML 包含当前工程连接／忽略等展示语义；PNG 是地图图片。ZIP、聚合 KML 和 PNG 图像统一在“导出轨迹”的类型下拉框中选择。完整历史和工程的备份仍使用 SQLite 完整备份。

## 任务与恢复

任务及事件仍保存在服务端独立 SQLite 中；中断写任务不会自动重放。网页在当前操作页面显示进度与结果，不再提供独立的处理记录面板和暂存文件管理列表。

错误在相关面板或地图错误区持续展示，普通成功消息短暂显示。底图切换失败保留原地图；资源错误可重试，网络恢复会重试失败资源。重新聚焦窗口不重建主地图。结果下载依赖任务登记的服务端文件，移动或清理后可能无法下载。

ZIP 和聚合 KML 导出会显示本次范围：全部轨迹或列表中批量勾选的轨迹。从批量选择进入后，可用左上角返回箭头回到列表并保留勾选；不再需要这次选择时，点击“取消选择并返回列表”清空勾选并退出批量操作。从顶部工具栏重新打开导出时，范围为全部轨迹。选定类型后点击“导出”，生成临时文件并自动下载，下载位置由浏览器决定。每个文件完整传到浏览器后，后台自动删除对应的临时文件；下载中断时，可在结果区重试尚未下载的文件。未下载的结果最多保留 24 小时，清理后需要重新导出。网页不提供服务端输出路径，也不会覆盖 CLI 导出的文件或更新归档的备份记录。执行明细和日志可在结果中的“查看执行详情”展开。删除轨迹会自动读取影响范围，只需一次“确认删除”。

轨迹详情的“下载轨迹”直接返回当前详情展示版本的原始 KML，内部按内容摘要绑定版本。不会创建处理任务或落盘到 uploads，也不显示版本 ID、结果或日志面板。历史版本下载仅在“查看历史操作”中提供。
